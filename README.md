# 🔒 AppLocker

**Bloqueador de aplicaciones anti-procrastinación** — App nativa de Android para enfocarte mejor.

Bloquea aplicaciones específicas durante un tiempo determinado para evitar distracciones y mejorar tu productividad. Diseñada con un enfoque estricto para evitar anulaciones y mantener el bloqueo activo.

![Version](https://img.shields.io/badge/version-1.0-red?style=flat-square)
![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)
![Status](https://img.shields.io/badge/status-Freelance-brightgreen?style=flat-square)

---

## Funcionalidades

- Selección de aplicaciones a bloquear desde la lista de instaladas
- Temporizador personalizable para definir el tiempo de bloqueo
- Pantalla de superposición (overlay) que impide el uso de apps bloqueadas
- Detección precisa de uso mediante Accessibility Service y Usage Stats
- Persistencia estricta: Auto-inicio al encender el dispositivo
- Protección contra desinstalación (Device Administrator)
- Interfaz moderna y fluida desarrollada 100% con Jetpack Compose

## Setup

```bash
git clone https://github.com/JuanEspinoza8/AppLocker.git
cd AppLocker
```

Abre el proyecto en **Android Studio**:
1. File > Open > Selecciona la carpeta `AppLocker`
2. Espera a que Gradle sincronice las dependencias
3. Ejecuta la app en un emulador o dispositivo físico

> **Nota:** Para el correcto funcionamiento en un dispositivo real, deberás otorgar permisos manuales de Accesibilidad, Superposición de pantalla y Acceso a uso de datos.
